# 3702. Longest Subsequence With Non-Zero Bitwise XOR

You are given an integer array `nums`.

Return the length of the longest subsequence in `nums` whose bitwise XOR is non-zero. 
If no such subsequence exists, return 0.

**Constraints:**

- `1 <= nums.length <= 10^5`
- `0 <= nums[i] <= 10^9`

## 基礎思路

本題要求找出一個子序列，使其所有元素的位元互斥或結果不為零，並回傳這個子序列的最大長度。乍看之下像是需要在指數量級的子序列空間中搜尋，但只要掌握互斥或的代數性質，就會發現答案的可能性其實極為有限。

在思考解法時，可掌握以下核心觀察：

- **互斥或具有自我抵銷性**：
  同一個數與整體互斥或再作一次運算，等同於把該元素從整體中移除，因此「刪除元素」與「再互斥一次」是等價操作。

- **最長候選必為全體本身**：
  子序列長度愈長愈有利，因此第一個該檢查的候選就是整個陣列；若全體的互斥或已經不為零，就不需要刪掉任何元素。

- **若全體互斥或為零，只需刪去一個非零元素**：
  當整體結果為零時，移除任一非零元素，剩餘部分的互斥或恰好等於該元素本身，必定不為零；因此答案至多也只會少一個元素。

- **唯一的無解情形是全部皆為零**：
  若陣列中不存在任何非零元素，則任意子序列的互斥或都必然為零，此時無論如何都無法達成條件。

依據以上特性，可以採用以下策略：

- **在單次掃描中同時累積「整體互斥或」與「整體位元或」**，前者用來判斷是否需要刪除元素，後者用來判斷是否存在非零元素。
- **依累積結果分三種情況直接回傳答案**：整體不為零則取全長；整體為零且全為零則無解；整體為零但存在非零元素則取全長減一。

此策略只需一次線性掃描與常數次判斷，即可在不枚舉任何子序列的情況下得到最佳解。

## 解題步驟

### Step 1：取得長度並初始化兩個累積器

先記錄陣列長度，並準備兩個累積器：其一累積整體的互斥或結果，用於判斷是否需要刪除元素；其二累積整體的位元或結果，僅在所有元素皆為零時才會維持為零。

```typescript
const length = nums.length;

// runningXor 決定情況一；只有當所有元素皆為 0 時，combinedOr 才會維持為 0。
let runningXor = 0;
let combinedOr = 0;
```

### Step 2：單次掃描同時累積互斥或與位元或

以一次線性掃描走訪所有元素，將每個值分別累積進互斥或與位元或兩個累積器；兩者皆為純 32 位元整數運算，可讓迴圈保持單型態以獲得較佳效能。

```typescript
// 單次掃描：兩個累積器皆為純 32 位元整數運算，因此迴圈可維持單型態。
for (let index = 0; index < length; index++) {
  const value = nums[index];
  runningXor ^= value;
  combinedOr |= value;
}
```

### Step 3：整體互斥或不為零時直接取全長

若掃描後的整體互斥或結果已不為零，代表整個陣列本身就是合法的子序列，無須捨棄任何元素，可直接回傳全長。

```typescript
// 整個陣列的互斥或已不為 0，因此不需要捨棄任何元素。
if (runningXor !== 0) {
  return length;
}
```

### Step 4：處理全部元素皆為零的無解情況

若整體互斥或為零，且整體位元或也為零，代表陣列中不存在任何非零元素；此時任意子序列的互斥或都必為零，無解，回傳 0。

```typescript
// 整體互斥或為 0 且不存在非零元素，因此任何子序列的互斥或都是 0。
if (combinedOr === 0) {
  return 0;
}
```

### Step 5：整體為零但存在非零元素時取全長減一

剩下的情況是整體互斥或為零，但陣列中確實存在非零元素；只要移除其中任一個非零元素，剩餘部分的互斥或即等於該元素本身而不為零，故答案為全長減一。

```typescript
// 整體互斥或為 0，因此只要移除恰好一個非零元素即可讓互斥或不為 0。
return length - 1;
```

## 時間複雜度

- 僅需一次線性掃描累積兩個累積器，為 $O(n)$；
- 後續三種情況的判斷皆為常數時間；
- 總時間複雜度為 $O(n)$。

> $O(n)$

## 空間複雜度

- 僅使用固定數量的純量變數儲存長度與兩個累積器；
- 未配置任何額外陣列或動態結構；
- 總空間複雜度為 $O(1)$。

> $O(1)$
