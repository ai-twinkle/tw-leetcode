# 2124. Check if All A's Appears Before All B's

Given a string `s` consisting of only the characters `'a'` and `'b'`, 
return true if every `'a'` appears before every `'b'` in the string. 
Otherwise, return `false`.

**Constraints:**

- `1 <= s.length <= 100`
- `s[i]` is either `'a'` or `'b'`.

## 基礎思路

本題要求判斷一個僅由 `'a'` 與 `'b'` 組成的字串中，是否所有 `'a'` 都出現在所有 `'b'` 之前。
換言之，合法字串必須呈現「前段全為 `'a'`、後段全為 `'b'`」的結構（任一段皆可為空）。

在思考解法時，可掌握以下核心觀察：

- **違規的本質是順序顛倒**：
  只要存在某個 `'a'` 出現在某個 `'b'` 之後，字串即不合法。

- **任何順序顛倒必定在相鄰位置留下痕跡**：
  若某個 `'b'` 之後出現了 `'a'`，則從該 `'b'` 往後走到該 `'a'` 的過程中，字元必定在某處由 `'b'` 轉為 `'a'`，因此字串中必然存在相鄰的 `"ba"` 片段。

- **反之亦然**：
  若字串中存在相鄰的 `"ba"`，則已直接構成一個 `'a'` 位於 `'b'` 之後的反例。

依據以上特性，可以採用以下策略：

- **將「全域的順序條件」轉化為「局部的相鄰片段檢查」**：字串合法，當且僅當其中不包含 `"ba"` 片段。
- **只需一次線性掃描判斷該片段是否存在**，再將結果取反即為答案。

此策略將原本需比較任意兩字元位置的問題，簡化為單一子字串的存在性判斷，簡潔且高效。

## 解題步驟

### Step 1：檢查字串中是否出現相鄰的 `"ba"` 片段

只要任一 `'a'` 出現在 `'b'` 之後，字串中必然存在相鄰的 `"ba"`；因此只需判斷該片段是否存在，並將結果取反即為答案。

```typescript
// 任何出現在 'b' 之後的 'a'，都必然使字串中某處存在相鄰的 "ba" 片段
return !s.includes("ba");
```

## 時間複雜度

- 子字串搜尋需掃描整個字串一次，且目標片段長度固定為 2；
- 每個位置的比對皆為常數時間。
- 總時間複雜度為 $O(n)$。

> $O(n)$

## 空間複雜度

- 僅進行字串搜尋，未配置任何額外的陣列或動態空間；
- 總空間複雜度為 $O(1)$。

> $O(1)$
