# 3870. Count Commas in Range

You are given an integer `n`.

Return the total number of commas used when writing all integers from `[1, n]` (inclusive) in standard number formatting.

In standard formatting:

- A comma is inserted after every three digits from the right.
- Numbers with fewer than 4 digits contain no commas.

**Constraints:**

- `1 <= n <= 10^5`

## 基礎思路

本題要求統計把區間內所有整數依照標準格式書寫時，總共會用到多少個逗號。
標準格式的規則是每三位數自右方插入一個逗號，因此位數不足四位的數字完全不含逗號。

在思考解法時，可掌握以下核心觀察：

- **逗號數量僅取決於位數**：
  一個整數會用到幾個逗號，完全由它的十進位位數決定，與數值本身的組成無關，因此可以按位數區間分群統計。

- **上限決定了位數的種類極為有限**：
  本題的上界僅到十萬，代表任何一個數最多為六位數，而六位數同樣只需要一個逗號，因此在整個區間內，含逗號的數字其逗號數皆為一。

- **問題退化為單純的計數**：
  既然每個含逗號的數字恰好貢獻一個逗號，總數就等於「區間內位數達四位以上的數字個數」，這是一個可以直接用算式求得的量，無須逐一列舉。

- **臨界點固定不變**：
  四位數的起點是一個固定常數，凡是小於該起點的輸入，答案必定為零；凡是大於等於該起點的輸入，其計數可由上界減去該起點前一個數直接得到。

依據以上特性，可以採用以下策略：

- **先以臨界點做快速判斷**，若上界尚未達到四位數，直接回傳零。
- **否則以閉區間長度公式直接計算含逗號的數字個數**，一次求得答案，不需任何迴圈。

此策略將原本看似需要逐數統計的問題，化簡為常數時間的算式求解。

## 解題步驟

### Step 1：快速處理不含任何逗號的情況

若上界尚未達到四位數的起點，則區間內所有數字皆為三位以下，不會出現任何逗號，可直接回傳 0。

```typescript
// 小於 1,000 的數字書寫時不含任何逗號
if (n < 1000) {
  return 0;
}
```

### Step 2：以區間長度直接計算逗號總數

在本題的上界限制下，四位到六位的數字都恰好含有一個逗號，因此含逗號的數字個數即為答案；該個數等於上界減去四位數起點的前一個數。

```typescript
// 在 n <= 10^5 的約束下，[1000, n] 中的每個數字都恰好含有一個逗號
return n - 999;
```

## 時間複雜度

- 僅執行一次比較與一次減法；
- 無任何迴圈或遞迴。
- 總時間複雜度為 $O(1)$。

> $O(1)$

## 空間複雜度

- 僅使用固定數量的暫存值；
- 無任何額外陣列或動態空間。
- 總空間複雜度為 $O(1)$。

> $O(1)$
