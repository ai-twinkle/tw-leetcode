# 3550. Smallest Index With Digit Sum Equal to Index

You are given an integer array `nums`.

Return the smallest index `i` such that the sum of the digits of `nums[i]` is equal to `i`.

If no such index exists, return `-1`.

**Constraints:**

- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 1000`

## 基礎思路

本題要求找出最小的索引，使得該位置上數值的各位數字之和恰好等於該索引本身；若不存在這樣的位置，則回傳 `-1`。由於題目只關心「最小」的索引，因此由前往後線性掃描，一旦命中即可立刻結束。

在思考解法時，可掌握以下核心觀察：

- **位數和的值域極為有限**：
  由於數值上限固定，位數和不可能超過某個很小的常數；換言之，能夠成立的索引只落在一個極短的前綴範圍內。

- **超出位數和上限的索引必定無解**：
  索引一旦大於可能的最大位數和，等式永遠不可能成立，因此掃描範圍可直接被截斷，不需走完整個陣列。

- **位數和具有遞迴的重疊結構**：
  任何數的位數和，等於其最低位數字加上「去掉最低位之後那個數」的位數和；此重疊性讓整張對照表能以單次線性遞推一次建成。

- **值域有限使查表成為可能**：
  由於輸入數值範圍固定且不大，可預先為整個值域建立位數和對照表，把每次的位數拆解運算降為一次陣列讀取。

依據以上特性，可以採用以下策略：

- **在模組載入時一次性建好整個值域的位數和對照表**，之後所有查詢都僅需常數時間的讀取。
- **以可能的最大位數和截斷掃描上限**，避免對不可能成立的索引做無謂比對。
- **由小到大線性掃描並即時回傳**，確保取得的必為最小索引；掃描結束仍無命中則回傳 `-1`。

此策略將重複的位數拆解成本完全前置，使單次查詢維持在常數時間，簡潔且高效。

## 解題步驟

### Step 1：定義可能的最大位數和常數

先依據題目約束推得值域內的最大位數和，作為後續截斷掃描範圍的依據。

```typescript
/** 在約束範圍 0..1000 內任何數值可能的最大位數和（來自 999）。 */
const MAXIMUM_DIGIT_SUM = 27;
```

### Step 2：建立整個值域的位數和對照表

配置一張涵蓋所有合法數值的表格，並利用「位數和等於最低位數字加上去掉最低位後之數的位數和」這個重疊性質，由小到大遞推填滿整張表。

```typescript
/**
 * 為約束範圍內的每個數值建立位數和查詢表。
 * @returns 一個 Uint8Array，其索引 v 儲存 v 的位數和。
 */
function buildDigitSumTable(): Uint8Array {
  const table = new Uint8Array(1001);

  // 每個數值都重複利用「自身去掉最低位」那個數已算好的位數和。
  for (let value = 1; value <= 1000; value++) {
    table[value] = (value % 10) + table[(value / 10) | 0];
  }

  return table;
}
```

### Step 3：於模組載入時預先建表

將對照表在模組載入階段建立一次，使得之後每一次呼叫都只是純粹的常數時間查表。

```typescript
// 於模組載入時預先計算一次，使每次呼叫都只是純 O(1) 的查表動作。
const DIGIT_SUM_TABLE = buildDigitSumTable();
```

### Step 4：計算實際需要掃描的上限

取得陣列長度後，將掃描上限取「陣列長度」與「最大位數和加一」之中較小者；因為索引一旦超過最大位數和，等式已不可能成立。

```typescript
const length = nums.length;

// 超過最大可達位數和的索引永遠不可能成立，因此限制掃描範圍。
const scanLimit = length < MAXIMUM_DIGIT_SUM + 1 ? length : MAXIMUM_DIGIT_SUM + 1;
```

### Step 5：由小到大掃描並即時回傳命中索引

在截斷後的範圍內由前往後逐一比對：若該位置數值的位數和等於當前索引，因掃描方向由小而大，此索引必為最小解，可立即回傳。

```typescript
for (let index = 0; index < scanLimit; index++) {
  if (DIGIT_SUM_TABLE[nums[index]] === index) {
    return index;
  }
}
```

### Step 6：無任何命中時回傳 -1

若整個有效範圍掃描完畢仍未找到符合條件的索引，代表答案不存在，回傳 `-1`。

```typescript
return -1;
```

## 時間複雜度

- 建表階段對固定值域遞推一次，為常數量級且僅於模組載入時執行一次；
- 每次查詢的掃描範圍被截斷為 $\min(n, 28)$，至多常數次比對；
- 每次比對皆為一次陣列讀取與一次整數比較，均為常數時間。
- 總時間複雜度為 $O(1)$。

> $O(1)$

## 空間複雜度

- 位數和對照表大小由固定值域決定，與輸入規模無關；
- 其餘僅使用固定數量的純量變數，無額外動態配置。
- 總空間複雜度為 $O(1)$。

> $O(1)$
