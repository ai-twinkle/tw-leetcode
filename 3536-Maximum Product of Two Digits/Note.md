# 3536. Maximum Product of Two Digits

You are given a positive integer `n`.

Return the maximum product of any two digits in `n`.

Note: You may use the same digit twice if it appears more than once in `n`.

**Constraints:**

- `10 <= n <= 10^9`

## 基礎思路

本題要求從一個正整數 `n` 的所有數字中，找出兩個數字使其乘積最大，並允許在同一數字出現多次時重複使用。

在思考解法時，可掌握以下核心觀察：

- **乘積最大化取決於最大的兩個數字**：
  由於所有數字皆為非負，欲使兩數乘積最大，只需選出數值最大的前兩個數字即可，無須考慮其他組合。

- **無須完整排序**：
  我們並不需要對所有數字排序，只要在逐一掃描過程中持續維護「目前最大」與「目前次大」兩個值即可。

- **逐位拆解即可取得所有數字**：
  透過反覆對 10 取餘與整數除法，即可由最低位往最高位依序取出每一個數字。

依據以上特性，可以採用以下策略：

- **維護兩個變數，分別記錄目前所見的最大與次大數字**。
- **逐位擷取數字並即時更新這兩個變數**，確保排名關係正確。
- **最終回傳最大與次大數字的乘積**即為答案。

此策略僅需一次線性掃描即可完成，簡潔且高效。

## 解題步驟

### Step 1：初始化最大與次大兩個數字

使用兩個變數分別追蹤目前掃描到的最大與次大數字，初始皆設為 0。

```typescript
// 追蹤目前所見的兩個最大數字
let largest = 0;
let secondLargest = 0;
```

### Step 2：逐位擷取數字並更新最大與次大值

透過 `while (n > 0)` 由最低位往最高位逐一取出數字；
每取出一位，便判斷其是否應更新最大值或次大值，以維持兩者的排名關係。

```typescript
// 由最低位往最高位依序擷取數字
while (n > 0) {
  const digit = n % 10;

  if (digit > largest) {
    secondLargest = largest;
    largest = digit;
  } else if (digit > secondLargest) {
    secondLargest = digit;
  }

  // ...
}
```

### Step 3：移除最低位，繼續處理剩餘數字

在完成當前位數的比較後，以整數除法去除最低位，讓迴圈得以處理下一位數字。

```typescript
while (n > 0) {
  // Step 2：擷取數字並更新最大與次大值

  // 將 n 向右移除一位（使用整數除法向零截斷）
  n = (n / 10) | 0;
}
```

### Step 4：回傳最大與次大數字的乘積

當所有數字皆處理完畢後，最大與次大值即為使乘積最大的兩個數字，將其相乘後回傳即為答案。

```typescript
// 回傳最大與次大數字的乘積
return largest * secondLargest;
```

## 時間複雜度

- 整數位數最多為常數（不超過 10 位），每位僅處理一次；
- 所有操作皆為常數時間。
- 總時間複雜度為 $O(1)$。

> $O(1)$

## 空間複雜度

- 僅使用固定數量的變數；
- 無任何額外陣列或動態空間。
- 總空間複雜度為 $O(1)$。

> $O(1)$
